# 🌍 Global CO2 Emissions Data Visualisation (2013–2023)

## 📌 Project Overview
This project presents an interactive data visualisation of global CO₂ emissions from 2013 to 2023. The goal is to transform complex climate data into clear, actionable insights using Tableau.

The dashboard enables users to explore emission trends across countries, analyse global patterns, and understand the relationship between industrial growth and environmental impact.

---

## 🎯 Objectives
- Analyse global CO₂ emission trends over time
- Identify top contributing countries
- Compare emissions across regions
- Enable interactive exploration using visual analytics

---

## 📊 Dataset
The dataset is sourced from:
- Our World in Data
- NOAA Climate Data
- NASA Climate Indicators
- Global Carbon Atlas
- Climate Watch (WRI)

The processed dataset includes:
- Year (2013–2023)
- Country
- CO₂ Emissions (MtCO₂)

---

## ⚙️ Data Processing
Data was cleaned and transformed using:
- Python (Pandas, NumPy)
- Excel (manual validation)
- Tableau (integration and visualisation)

Steps included:
- Removing null values and duplicates
- Filtering data between 2013–2023
- Restructuring data into long format

---

## 📈 Visualisations
The Tableau dashboard includes:

- 🌐 Global CO₂ Trend (Line Chart)
- 🏆 Top 10 Emitting Countries (Bar Chart)
- 🗺️ CO₂ Emissions by Country (Choropleth Map)
- 📉 Country-wise Emission Trends (Multi-line Chart)
- 🎞️ Animated Global Emissions Map

---

## 🧠 Key Insights
- Global CO₂ emissions show an overall increasing trend
- China, USA, and India are the largest contributors
- Developed countries show stabilisation trends
- Developing economies show rapid emission growth

---

## 🔍 Features
- Interactive filters (Year, Country)
- Hover tooltips with detailed metrics
- Animated timeline
- Cross-filtering between visualisations

---

## 🚧 Limitations
- No integration of temperature or sea-level data
- Limited socioeconomic correlation analysis
- Uses absolute emissions (not per capita)

---

## 🔮 Future Improvements
- Include per-capita emissions
- Add GDP and energy consumption correlation
- Integrate climate indicators (temperature, sea level)
- Improve forecasting models
